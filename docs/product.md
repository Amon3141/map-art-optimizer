# GPSアート作成機 — プロダクト

## 名前

**GPSアート作成機** — Strava アートのように、道路に沿った一筆書きルートを地図上で作ることを目指す。

## 既存アプリとの差

多くの既存ツールは「地図上に形を描く → その形に道路をスナップ」であり、描いた形の位置・大きさ・回転に縛られる。

本アプリは **別キャンバスへの手描き** を入力とし、探索エリア内で **位置・回転・スケールを最適化** して道路ネット上で形を表現する（最適化は未実装）。

## 初期スコープ（現段階）

- フロント: ライトトーンの1ページUI、手書きキャンバス（単一ストローク）、確定形のサイドバープレビュー、地図表示。`VITE_APP_ENV=development` 時のみ距離の目安（整数 km）・テキストツール・ホームから `/debug` へリンク。
- バックエンド: 最適化なし。OSM/Overpass 確認用のプロキシのみ。

## 非目標（今はやらない）

- 最適化アルゴリズム、±2 km 程度の距離制約の実装。
- 非一筆書き入力の自動一筆書き化。
- GPX 等の出力仕様の確定・実装。

## デバッグ UI

`frontend` のデバッグ用ページ・コンポーネントは **都度フル書き換え可**。ユーザーの明示指示がない限り、過去のデバッグ UI を残す必要はない。

## プライバシー（方針メモ）

ルート・位置はクライアント中心。サーバ側で不要な個人関連ログを残さない方針とする（実装時に従う）。
